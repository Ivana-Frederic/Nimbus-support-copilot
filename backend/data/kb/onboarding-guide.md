# Creating your account

Sign up at nimbuscloud.example/signup with a work email. You'll be asked to
create your first workspace and choose a plan (you can start on Starter and
upgrade later without losing data).

# First steps after signup

1. Connect your first data source from the Dashboard's "Connect" button.
2. Generate an API token from Settings > API Tokens if you plan to integrate
   programmatically.
3. Invite teammates from Settings > Team > Invite. Invited members get
   read-only access by default until an admin promotes them.
4. Explore the quickstart templates under Dashboard > Templates to see a
   working example end to end in under 5 minutes.

# Inviting your team

Only workspace admins can invite new members. Invited users receive an
email with a signup link valid for 7 days. You can resend or revoke pending
invites from Settings > Team.

# Choosing the right plan to start

Most teams start on Starter to evaluate the product, then move to Pro once
they exceed 1,000 API calls/day or need more than one paid seat. You do not
need to talk to sales to upgrade, it's self-serve from Settings > Billing.

# Getting help

The in-app chat (this copilot!) answers most setup questions instantly. For
anything it can't resolve, it will point you to a human support agent.
